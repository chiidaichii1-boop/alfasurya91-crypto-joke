## Entry

One line, under 200 characters, about crypto and trading life:

> I bought the dip. The dip bought a shovel, dug deeper, and now I'm a long-term investor against my will.

## How it works

`main.py` (Python 3 standard library only) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
The output is fully deterministic: the same line every run.

## Run

```sh
python3 main.py
```
